# 8-String Lyre: How Things Change
## Chord Progression Analysis Comparison

**Date:** 2025-10-20

---

## Executive Summary

Adding an 8th string (completing the octave) provides **moderate but meaningful improvements**:

✓ **+1 root position triad** per mode (IV chord gains root position)
✓ **+3 total voicings** per mode (~43% increase)
✓ **Better voice leading options** with more flexibility
✓ **Plagal cadences (IV-I) much improved** in all modes

**However:** Even with 8 strings, no mode achieves all 7 triads in root position.

---

## Summary Comparison Table

| Metric | 7-String | 8-String | Improvement |
|--------|----------|----------|-------------|
| **Root position triads** | 3/7 | 4/7 | +1 (+33%) |
| **Total voicings** | 7 per mode | 10 per mode | +3 (+43%) |
| **String combinations** | C(7,3) = 35 | C(8,3) = 56 | +21 (+60%) |
| **IV chord root position** | 0/7 modes | 7/7 modes | Universal gain |
| **All triads in root** | 0/7 modes | 0/7 modes | Not achieved |

## What Changes With 8 Strings

### String Layout

**7-string lyre:**
```
String: 1  2  3  4  5  6  7
Degree: 0  1  2  3  4  5  6
```

**8-string lyre:**
```
String: 1  2  3  4  5  6  7  8
Degree: 0  1  2  3  4  5  6  0 (octave)
```

The 8th string is the octave of the 1st string, completing the scale.

### Chord Availability

**What gains root position:**
- **IV chord** - All modes gain this universally
- This is the ONLY chord that gains root position

**What stays the same:**
- Tonic (I or i) chord voicings
- Dominant (V or v) chord voicings
- Other chords remain in inversions or gain additional inversion options

## Mode-by-Mode Analysis

### DORIOS (Modern Phrygian)

**7-string:**
- Root position: i, II, III (3/7)
- Total voicings: 7
- IV chord: Inversions only

**8-string:**
- Root position: i, II, III, **iv** (4/7)
- Total voicings: 10 (+3)
- **Gained: iv in root position**

**Impact:**
- **Plagal cadence (iv-i) dramatically improved**
- Old: IV-I was the STRONGEST cadence at 39.64 even with inversions
- New: With iv in root position, expect complexity ~35-37 (even better!)
- This makes DORIOS more usable since its diminished V (68.93) can be avoided

## Overall Impact Assessment

### Major Improvements

**1. Plagal Cadences (IV-I)**
- **Before:** 39.64 - 71.40 (depending on mode, all with inversions)
- **After (estimated):** 35-40 (with root position)
- **Impact:** ~30-35 point improvement in most modes
- **Significance:** HIGH - Makes plagal cadence viable alternative

**2. Voice Leading Flexibility**
- +3 voicings per mode gives more options
- Smoother voice leading possible with extra string
- More choices for chord connections

**3. Modes That Benefit Most**

**LYDIOS & HYPOPHRYGIOS** (Major modes)
- Gain major IV in root position
- Enables classic I-IV-V-I progressions
- **"Amen" cadence now properly voiced**
- Huge practical improvement

**DORIOS** (Problematic mode)
- Diminished V makes V-I weak (68.93)
- iv-i now even stronger with root position
- Makes mode much more usable

**MIXOLYDIOS** (Worst mode)
- Diminished tonic makes V-I terrible (106.05)
- iv-i° becomes primary cadence
- Still problematic but more options

### Minimal Improvements

**HYPOLYDIOS:**
- Gains diminished iv°
- Not particularly helpful (still complex)
- V-I already perfect at 15.71

**PHRYGIOS & HYPODORIOS:**
- Already have good cadences (V-I: 16.91)
- iv in root position provides variety
- Nice to have but not game-changing

## Practical Recommendations

### Should You Get 8 Strings Instead of 7?

**YES, if:**
- ✓ You want traditional plagal cadences (IV-I "Amen")
- ✓ You're playing in major modes (LYDIOS, HYPOLYDIOS, HYPOPHRYGIOS)
- ✓ You want more voice leading options
- ✓ You're using DORIOS or MIXOLYDIOS (problematic modes benefit most)
- ✓ The extra string doesn't significantly increase cost/complexity

**NO, if:**
- ✗ You primarily use V-I cadences (unchanged)
- ✗ You're happy with the modes that work well (LYDIOS, PHRYGIOS, etc.)
- ✗ You want to keep the instrument simpler
- ✗ Cost or build complexity is a factor

### Mode Recommendations With 8 Strings

**Tier 1: Excellent (no change)**
1. LYDIOS - V-I: 15.71 (best overall)
2. HYPOLYDIOS - V-I: 15.71 (best overall)
3. PHRYGIOS - V-I: 16.91
4. HYPODORIOS - V-I: 16.91
5. HYPOPHRYGIOS - V-I: 16.91

**Tier 2: Now More Usable**
6. DORIOS - Use iv-i (~35) instead of V-I (68.93)
7. MIXOLYDIOS - Use iv-i° (~37) instead of V-I (106.05)

### Progression Recommendations (8-String)

**Major modes (LYDIOS, HYPOLYDIOS, HYPOPHRYGIOS):**
```
Primary:   V-I     (15.71-16.91) - Still best
Secondary: IV-I    (~36)         - Now viable!
Common:    I-IV-V-I              - Now properly voiced
```

**Minor modes (PHRYGIOS, HYPODORIOS):**
```
Primary:   v-i     (16.91)       - Still best
Secondary: iv-i    (~35-37)      - Now good alternative
Common:    i-iv-v-i              - More options
```

**Problematic modes (DORIOS, MIXOLYDIOS):**
```
Primary:   iv-i    (~35-37)      - Use this instead!
Avoid:     V-I     (68-106)      - Still problematic
Strategy:  Emphasize plagal, avoid authentic
```

## Technical Details

### Voicing Combinations

**7-string:**
- 3-note chords: C(7,3) = 35 possible combinations
- Average: 7 valid voicings per mode (for 7 triads)
- Many duplicates/non-triadic combinations

**8-string:**
- 3-note chords: C(8,3) = 56 possible combinations
- Average: 10 valid voicings per mode
- +60% more combinations, +43% more valid voicings

### Why IV Gains Root Position

The IV chord uses scale degrees [3, 5, 0]:
- In C major: F-A-C
- 7-string: strings [4,6,1] required (not adjacent, hard to voice in root position)
- 8-string: strings [4,6,8] possible (8th string = octave C, enables root position!)

The 8th string (octave of 1st) completes triads that need the tonic note in the upper octave.

### Just Intonation Unchanged

All complexity values use just intonation whether 7 or 8 strings.
The 8th string maintains the same frequency ratios.

## Conclusion

Adding an 8th string provides **meaningful but not revolutionary** improvements:

**Biggest Win:** Plagal cadences (IV-I) become properly voiced
- ~35 point complexity reduction in major modes
- Makes "Amen" cadence and I-IV-V-I progressions properly playable
- Especially helpful in LYDIOS, HYPOLYDIOS, HYPOPHRYGIOS

**Biggest Benefit:** Problematic modes become more usable
- DORIOS and MIXOLYDIOS gain viable alternative cadences
- Changes tier ranking from "avoid" to "usable with workarounds"

**No Change:** Best cadences stay the same
- V-I still 15.71-16.91 in good modes
- Core harmonic strength unchanged
- Top tier modes still top tier

**Verdict:** **Recommended** if you want full traditional harmonic vocabulary, especially for major mode playing. Not essential if you're happy with V-I based progressions.
